# 사이먼 🎵

빛나고 소리 나는 색 패드의 순서를 외워서 똑같이 누르는 기억 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: 빛난 패드를 **순서대로 누릅니다**(폰은 톡, PC 는 클릭 또는 `Q` `W` / `A` `S` 키, 숫자 `1`~`4`). `P` 일시정지, `M` 소리. 창이 가려지면 저절로 일시정지합니다.
- 규칙은 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- 한 라운드: 잠깐 준비(0.8초) → 패드가 하나씩 **빛나며 소리**(빨강 도 · 파랑 미 · 노랑 솔 · 초록 높은 도) → **내 차례**에 같은 순서로 누르기. 다 맞히면 순서에 **하나가 더해져** 처음부터 다시 보여 줍니다. 같은 패드가 세 번 이상 이어지지 않게 만듭니다.
- **빨라짐**: 순서가 5개 · 9개 · 13개가 되면 한 번 빛나는 간격이 줄어듭니다(보통 0.7 → 0.55 → 0.42 → 0.34초, 쉬움 0.9 → 0.75 → 0.62 → 0.52초, 거꾸로 0.8 → 0.65 → 0.52 → 0.42초).
- **난이도**: 「쉬움」 ❤ 3개·시간 제한 없음. 「보통」 한 번 틀리면 끝(고전 규칙)·한 번 누르는 데 5초. 「거꾸로」 보여 준 순서를 **뒤에서부터** 누르기·❤ 2개·누르는 데 7초.
- 틀리면(또는 시간 초과) 맞는 패드를 보여 주고 ❤ 가 줄며, ❤ 가 남아 있으면 **같은 순서를 다시** 보여 줍니다. ❤ 가 0 이면 끝입니다. 점수는 맞힌 순서 길이의 합, 기록은 **성공한 가장 긴 순서**(난이도별로 따로 저장, 로비 기록은 보통)입니다.

## 확인한 것
- 규칙 시험 13개: 단계별 속도 단조 감소·쉬움이 더 느림, 같은 시드 같은 순서와 세 번 이상 연속 금지, 보여 주는 단계에서 패드가 한 번씩 순서대로 빛나는 시각, 내 차례가 아니면 입력 무시, 성공하면 길이가 늘고 점수가 쌓임, 거꾸로 모드의 정답 순서, 틀렸을 때 ❤ 감소와 같은 순서 재생·마지막 ❤ 이면 끝, 누르는 시간 제한(쉬움은 없음·누를 때마다 다시 시작), 연습 모드, 큰 시간 걸음 일관성, 완벽한 플레이어는 31개까지 감.
- 처음 시험에서 「순서를 하나 더하는 반복 조건」이 끝나지 않는 버그를 찾아 고쳤습니다.
- **사람이 몇 개까지 외우는지(체감 난이도)는 측정하지 못했습니다.** 사람은 보통 7±2개 정도를 한 번에 기억한다고 알려져 있어, 7~9개 근처부터 틀리는 게 자연스러울 것으로 봅니다(추정).

## 참고한 것과 제가 정한 값
- 「빛과 소리의 순서를 따라 누르는」 널리 알려진 형식(사이먼 게임)을 따랐고, 색 · 음 · 속도 · 제한 시간은 제가 정한 값입니다. 온라인 대전은 없습니다.
